# Security policy

Only the latest main revision is supported.

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting under this repository's Security tab. If that is unavailable,
email licensing@djcdevelopment.com with a subject beginning [SECURITY].

Expect acknowledgment within seven days and a fix, mitigation, or documented
accepted-risk disposition within 90 days. Please hold public disclosure for 90 days
or until a fix ships, whichever comes first. There is no bounty program.

Quest packages and release artifacts must not contain credentials, private player
data, machine-specific paths, or unverified binaries. The package privacy gate and
full-history gitleaks scan are mandatory before publication.
