# 0007 — Lap gates are keyed to a content profile

Status: accepted — landed 2026-08-20 with strategy workstream W4.

## Context

The validation lap's machine gates were written for the first quest they ever
gated. `ValidateRevision` and `ConfirmActivation` called `Assert-WoodboundCandidate`,
which asserted the title "The Woodbound Signal", exactly three stages, exactly one
transition per stage, and three specific triggers. Phase 3 exit session 2 ran the
desperate-defense content instead, so those gates could not run at all: the staging
proof — activation receipt, active-set agreement, activation-id shape — was
assembled by hand at the keyboard while the seat waited. A harness that only trusts
one quest cannot gate the next lap, which is every lap after the first.

The gates were also asserting the wrong things about that one quest. Stage and
route ids are generated by Studio and pinning them would have made the gate brittle;
the effects a lap's verdicts actually depend on — eight Greylings, a 600-second
ward — were pinned nowhere at all.

## Decision

A lap declares a **content profile**: the authored shape it gates against, as data.
A profile pins the title, the stage count, each stage's routes in the engine's own
priority order, and per route the trigger shape, the effects, the destination, the
ending, and the exact copy (with a second-revision copy override where the lap's
update beat needs one). It pins nothing Studio is free to generate — stage ids and
route ids stay unpinned.

`Prepare` records the profile in the run context and every later step resolves it
from there, so a run cannot switch content mid-lap. The normalized-experience hash
that proves "r2 changed nothing but its copy" blanks every message text rather than
one known final message.

## Consequences

- A non-Woodbound lap gets the same machine refusals the first lap had, including
  the activation-gated staging of ADR 0001.
- Content drift in the numbers a verdict depends on is refused by the gate rather
  than discovered mid-session — a six-Greyling wave can no longer answer a verdict
  about clearing eight. The self-test proves this with a second profile.
- New content costs a profile entry. That is the intended price: writing down what
  the lap depends on is the same act as being able to gate it.
